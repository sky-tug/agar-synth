# --- synthetic arms ---------------------------------------------------------
# Each of these trains on a real subset PLUS synthetic plates, topped up to the
# full-data size (2,987 images), so every one of them costs a full G100 run.
# The list is built by scripts/make_arm_lists.py as generation finishes each
# level, and gen_queue.sh calls it automatically.
#
# Order is deliberate. Generation produces level 100 first, then 10, then 25,
# then 50, and the training queue holds the GPU whenever it has work -- so the
# two arms that decide the paper come out COMPLETE and early rather than six
# arms coming out half-measured:
#
#   S100   does synthetic data work AT ALL, on its own, with no real images?
#   G10+S  does it help where real data is scarcest -- the case for the method
#   G25+S  the midpoint, directly comparable with the B and M arms above
#
# The amount sweep and G50+S come last: "how much synthetic is best" and "does
# it help when you already have half the real data" are refinements, not the
# claim.
